# INFINITELY

A responsive, Bored.com-inspired discovery portal with original branding and content.

## Features
- Random "I'm bored" recommendation picker
- Search and category filters
- 30+ curated internet discoveries, games, visual toys, brain teasers and learning links
- Save favorites locally in the visitor's browser
- Responsive desktop and mobile layout
- No account, backend, build step, or tracking required

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will publish the site at:

https://blackback.github.io/infinitely-fun/

The first publication can take a few minutes.
